# ZeroCrowd-Labs

Lab materials and exercises for [ZeroCrowd](https://github.com/dr-skaragiannis/ZeroCrowd) (GameHack CTF platform).

## Repository

Public GitHub: https://github.com/dr-skaragiannis/ZeroCrowd-Labs

## Local development

If you already have this project on your machine:

```bash
git remote add origin https://github.com/dr-skaragiannis/ZeroCrowd-Labs.git
git push -u origin main
```

Or update an existing clone:

```bash
git pull origin main
```
